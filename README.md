# Science Tools Site

Static HTML tools hosted on GitHub Pages. Teaching resources only —
keep personal projects (Speaker Build Studio, Bag End Hub) in a separate repo.

## Folder layout

    yourusername.github.io/
    │
    ├── index.html      <- hub / front page (goes here, at the top level)
    │
    ├── year7/          <- Year 7 lesson tools
    ├── year8/          <- Year 8 lesson tools
    ├── year9/          <- Year 9 lesson tools
    ├── year10/         <- Year 10 / PDHPE tools
    │
    ├── games/          <- review games, reused across topics
    └── tools/          <- teacher utilities (e.g. Teacher Dashboard)

## Naming rules for HTML files

- lowercase only
- hyphens instead of spaces:  contact-tracing.html  (not "Contact Tracing.html")
- no spaces or capitals
- don't repeat the year — the folder already says it:
  year9/contact-tracing.html          YES
  year9/year9-contact-tracing.html    NO

## Your URLs will be

- Front page:  https://yourusername.github.io/
- A tool:      https://yourusername.github.io/year9/contact-tracing.html

## Next steps

1. Drop your HTML files into the right folders above.
2. Delete the "_add-files-here.txt" placeholder from any folder once it has real files.
3. Upload the folders to your repo (Add file > Upload files > drag the folders in).
4. Settings > Pages > Deploy from a branch > main > / (root) > Save.
5. Wait 1-2 min, then test a link.

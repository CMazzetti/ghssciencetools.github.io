Recommended class format

  1. Use four balanced teams.
  2. Rotate the spokesperson after every question.
  3. During multiple-choice rounds, teams discuss quietly before the spokesperson locks in an answer.
  4. Teams that escape the Chaser qualify for the Final Chase.
  5. Finish with all qualifying students working together against the computer Chaser.

How to run the game

  1. Cash Builder: Read each question aloud. Click Correct or Pass. Each correct answer adds $1,000.
  2. Offers: The team chooses a low, middle or high offer. Higher rewards start closer to the Chaser.
  3. Head-to-Head: The team selects an answer, then the computer Chaser responds. Reach home before being caught.
  4. Final Chase – Team: All qualifying teams answer rapid-fire questions to set a target.
  5. Final Chase – Chaser: The Chaser tries to reach the target. When the Chaser is wrong, the class gets a pushback chance.

Participation tip

Rotate the spokesperson after every question, or use mini-whiteboards so every team must commit before an answer is revealed.

Keyboard shortcuts

C correct, P pass, 1–4 select an option, Space reveal or continue.

How to play

  1. Read the prompts. Each category card shows a specific challenge this round — the prompts change every round.
  2. Spin the letter. Every answer must start with that letter.
  3. Start the timer. Write ONE answer per card that fits the prompt AND starts with the letter.
  4. Ignore "A" and "The". "The Weeknd" counts as W, not T.
  5. Share answers card by card when time is up.
  6. Scoring: a valid answer that no other team wrote = 1 point. If two or more teams wrote the same thing, everyone gets zero for it.
  7. Bonus (optional): +1 extra point if the answer uses the letter twice, like "Silver Snake".
Got a brutal letter–prompt combo? The teacher can hit New prompts before starting the timer. Some combos have no example answer at all — a blank is a fair result in Scattergories. The teacher is always the final judge.

How to use this template

  1. Open Create or Edit Game.
  2. Change titles, categories, clues, accepted answers, explanations and point values.
  3. Add or remove categories and question rows.
  4. Choose standard or wager questions.
  5. Save to the browser or export a JSON backup.
  6. Open Play Current Game, enter team names and begin.

Keyboard shortcuts: Space = reveal, C = correct, X = incorrect, N = no score, 1–8 = select team.
